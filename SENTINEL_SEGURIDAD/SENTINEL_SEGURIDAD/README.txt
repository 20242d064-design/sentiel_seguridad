SENTINEL - SITIO WEB DE SEGURIDAD

COMO ABRIR EN VISUAL STUDIO CODE
1. Descomprime SENTINEL_SEGURIDAD.zip.
2. Abre Visual Studio Code.
3. Selecciona Archivo > Abrir carpeta y elige SENTINEL_SEGURIDAD.
4. Abre index.html en el navegador. Recomendado: instalar la extensión Live Server y pulsar "Go Live".

FUNCIONES INCLUIDAS
- Página de inicio adaptable a celular y computadora.
- Secciones de soluciones, catálogo, nosotros y contacto.
- Catálogo con filtros y buscador.
- Carrito funcional con cantidades y total.
- Solicitud de pedido por WhatsApp.
- Formulario de asesoría que prepara un mensaje de WhatsApp.
- Asistente virtual demostrativo con respuestas automáticas.

PERSONALIZACIÓN IMPORTANTE
Abre js/script.js y cambia la constante phone dentro de la función whatsapp:
const phone = '51999999999';
Coloca tu número real con código de país, sin + ni espacios.

En index.html cambia SENTINEL, el correo ventas@sentinel.pe, la ubicación y el teléfono de muestra.
Los productos, precios e imágenes son referenciales. Las imágenes se cargan desde internet; se necesita conexión para verlas.
El asistente es una demostración local de respuestas automáticas, no está conectado a una API de inteligencia artificial.
